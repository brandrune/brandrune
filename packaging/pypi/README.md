# brandrune

**Names you can read. Domains that are really open.**

Brandrune is a free Claude Code skill for naming what you build. Describe it in a
sentence. Claude writes about 150 names, and a small script asks the domain
registries about every one. A name is only called open when the registry says it
has no record of it.

This PyPI package is a pointer. The skill installs inside Claude Code:

```
/plugin marketplace add brandrune/brandrune
/plugin install brandrune@brandrune
```

Running `brandrune` after `pip install brandrune` prints the same two lines.

- Site: https://brandrune.com
- Source: https://github.com/brandrune/brandrune

Formerly published as `weavenames`.
