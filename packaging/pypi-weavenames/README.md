# weavenames is now Brandrune

This project was renamed to **Brandrune**: https://brandrune.com

It is now a free Claude Code skill. Install it from inside Claude Code:

```
/plugin marketplace add brandrune/brandrune
/plugin install brandrune@brandrune
```

The old weavenames 0.0.1 engine on PyPI is no longer maintained. This 0.0.2
release only prints the lines above.
